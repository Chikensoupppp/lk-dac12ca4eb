# SwipeLater branding

| Item | Value |
|---|---|
| Brand name | SwipeLater |
| App Store title | `SwipeLater: Focus App Blocker` (29 chars) |
| Subtitle | `Block Apps. Lock In.` (20 chars) |
| Tagline | Your distractions can wait. |
| Home-screen name | SwipeLater |

SwipeLater is a timed app blocker. It is not mainly a study timer or a screen-time tracker.

## What the name changed in the app
Display names, the header, the Plus card, notifications, widget and Live Activity text,
camera and local-network permission text, partner-flow text.

## What stays the same on purpose
- Bundle IDs, target and folder names (`LockIn*`), UserDefaults keys (`lockin.*`).
- The `nogbox://` link scheme and the `_nogbox._tcp` Bonjour name (the PC app uses them).
- The Windows PC app is still called Nogbox until a PC release renames it. Phone text that
  talks about the PC still says "Nogbox".
- The verb "lock in" in the copy and the "LOCK IN" accessibility label.
